# Root-Me

Repository lưu trữ quá trình học tập và giải các **Root-Me challenges**, bao gồm writeup, phương pháp phân tích và các script hỗ trợ.

Mục tiêu là ghi lại quá trình thực hành Cybersecurity và xây dựng tài liệu tham khảo cho các kỹ thuật có thể áp dụng trong **CTF, Penetration Testing và Reverse Engineering**.

## Cấu trúc Repository

```text
.
├── Cracking/
│   └── ...
│
└── writeup.ctb
```

## Writeup

Writeup tập trung vào quá trình giải challenge:

```text
1. Thông tin challenge
2. Phân tích ban đầu
3. Xác định phương pháp giải
4. Phân tích dữ liệu / chương trình
5. Khai thác / cracking
6. Script hỗ trợ
7. Kết quả
8. Kiến thức rút ra
```

Không chỉ ghi lại đáp án cuối cùng mà cố gắng giải thích **vì sao phương pháp đó hoạt động**.

## Mục tiêu

Repository được sử dụng để:

* Luyện tập CTF
* Cải thiện kỹ năng Linux
* Phát triển kỹ năng scripting
* Làm quen với phương pháp phân tích và khai thác
* Ghi lại kiến thức đã học

## Disclaimer

Repository phục vụ mục đích **học tập và nghiên cứu Cybersecurity**.

Các kỹ thuật được trình bày chỉ nên được sử dụng trong CTF, lab hoặc trên các hệ thống mà bạn được phép kiểm thử.
